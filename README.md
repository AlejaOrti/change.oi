Proyecto desarrollado como parte de la formación en Desarrollo Frontend de Alura Latam, enfocado en la creación de una landing page moderna y responsiva para una empresa orientada a la innovación y transformación digital.

El objetivo del proyecto fue aplicar conocimientos de HTML y CSS, desarrollando una interfaz atractiva, organizada y adaptable a diferentes dispositivos, siguiendo buenas prácticas de diseño web y experiencia de usuario.
